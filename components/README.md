# Streaming Chat Component

A React component that implements real-time streaming chat using Server-Sent Events (SSE) with a POST request.

## Features

- ✅ Real-time streaming with SSE over POST requests
- ✅ Proper buffering and handling of incomplete chunks
- ✅ TypeScript support
- ✅ Modern, responsive UI design
- ✅ Auto-scroll to latest messages
- ✅ Request cancellation support
- ✅ Error handling
- ✅ 36-character UUID thread IDs (UUID v4 format)
